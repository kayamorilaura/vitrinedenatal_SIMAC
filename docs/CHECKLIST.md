# Checklist — requisitos e entrega v2

## Requisitos do enunciado 2026/27

- [ ] v0 — Decorações de Natal 2026 / Ano Novo 2027 no MediaCenter.
- [ ] v0 — Pelo menos 3 objetos decorativos distintos; animação simples.
- [ ] v1 — Cena integrada e imagem de fundo adequada.
- [ ] v1 — Pelo menos 4 objetos decorativos diferentes.
- [ ] v1 — Animação simples + animação complexa com movimento temporizado.
- [ ] v1 — Pelo menos 4 teclas para controlo de animações.
- [ ] v2 — Duas cenas festivas distintas com fundos apropriados.
- [ ] v2 — Efeitos sonoros festivos associados às animações.
- [ ] v2 — Teclado 0–F completamente funcional.
- [ ] v2 — Pelo menos 6 teclas distintas para animação e/ou som.
- [ ] v2 — Rotinas adequadas e comentários úteis.

## Qualidade do programa

- [ ] Circuito e código testados no SIMAC 2.3.0.
- [ ] Verificar limites de posições e cores ARGB.
- [ ] Não usar caminhos absolutos para imagens/sons do circuito.
- [ ] Evitar repetição de código e organizar rotinas por função.
- [ ] Testar mudança de cena em pausa e durante animação.
- [ ] Testar alterações repetidas de velocidade, áudio e limpeza.
- [ ] Validar execução num segundo computador ou pasta diferente.

## Entrega

- [ ] Material prático (.asm, .cir e todos os assets necessários).
- [ ] Relatório técnico (máximo de 6 páginas) com manual de utilizador, comentários e análise crítica.
- [ ] Demonstração oral com testes preparados e explicação das decisões.

**Avaliação:** MP aproximadamente 40% funcionalidade, 30% organização, 20% eficiência e 10% criatividade. Nota final do projeto = menor valor entre MP, apresentação oral e relatório técnico. **14 valores são indicativos para a v2 de MP, não uma garantia.**
